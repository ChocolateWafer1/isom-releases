# Isom releases

Downloads for **Isom**, a wandering world: an isometric pixel-art game set on a huge procedural continent you can
explore, dig into and build on.

The easiest way to play is the **Firefly Launcher**. It installs Isom with one click, updates it whenever a new
version comes out, and plays it. Get the launcher once from
[goober-releases](https://github.com/ChocolateWafer1/goober-releases/releases) and it keeps itself up to date from
then on.

`versions.json` is the list the launcher reads. Every version's zip is attached to its
[release](https://github.com/ChocolateWafer1/isom-releases/releases).
